# GovP2P SecureTransfer
### 自治体セキュリティ基準対応・端末間直接通信（P2P）ファイル＆テキスト共有システム

> **外部サーバーを一切介さず、ブラウザ同士が直接つながる。**  
> 自治体PCの厳しいセキュリティ制限下から一般のスマートフォンまで、大容量ファイルとテキストを高速・安全・簡単に共有できるゼロログP2Pシステムです。

---

## 主な特徴

- **完全サーバーレス＆ゼロログ**: ファイルやテキストデータは外部サーバーに1バイトも保存・中継されません。ブラウザ端末間で直接通信（WebRTC DataChannel）します。
- **Web Crypto 二重暗号化 (E2EE)**: WebRTC標準のDTLS暗号化に加え、Web Crypto API による **AES-256-GCM** でチャンク単位二重暗号化。シグナリングサーバーやネットワーク管理者でも盗聴・復号は不可能です。
- **TURN over TLS (Port 443 TCP) 対応**: 自治体プロキシ環境下でUDPが遮断されている場合でも、443ポート（HTTPS）を通るTLSトンネルでNAT越えを支援。
- **厳格セキュリティ下モード (動的QRコード光転送)**: 外部ネットワークが完全遮断された環境でも、ブラウザ内Gzipリアルタイム圧縮と動的QRコード・カメラ連写により、ネットワーク通信を一切使わずにファイルを直接転送。
- **徹底的な超高速化ロジック**: 
  - **64KB最適化チャンキング**: SCTP通信のMTUとバッファ効率を最大化。
  - **Backpressure（背圧）制御**: `bufferedAmountLowThreshold` によるイベント駆動ストリーミング。ブラウザのバッファ溢れやメモリ枯渇（OOM）を防ぎます。
  - **オンデマンドスライス**: `Blob.slice()` による逐次読み込みで、大容量ファイルでも安定転送。
- **SHA-256 完全性検証**: 送信前と受信完了時にファイル全体のSHA-256ハッシュ値を自動計算・照合し、データの破損や改ざんを検知。
- **手間のない簡単接続**: 
  - **6桁PINコード入力**: 数字を入力するだけで即時ペアリング。
  - **QRコードスキャン**: スマホのカメラやPCのWebカメラでQRをかざすだけで一発接続。
  - **接続キャンセル・タイムアウト**: 接続試行中いつでも中止可能、15秒で自動タイムアウト。
- **テキスト自動タブ切り替え**: テキスト受信時に自動でテキスト共有タブに切り替わります。
- **閉域網（LGWAN等）対応**: インターネット通信が遮断された環境でも、画面上のSDPテキストを手動交換することで同一LAN内でWebRTC接続を確立可能。

## 自治体PC・金融機関でも安全とされる理由（セキュリティ仕様）

| セキュリティ項目 | 一般的なクラウドストレージ / ファイル転送サービス | GovP2P SecureTransfer |
| :--- | :--- | :--- |
| **データ保存場所** | 外部クラウドサーバー（漏洩・不正アクセスリスク） | **端末のメモリ内のみ**（外部保存ゼロ） |
| **通信経路** | 端末 ➔ 外部サーバー ➔ 相手端末 | **端末 ➔ 相手端末（直接通信または光通信）** |
| **暗号化強度** | サーバー側で復号可能な場合が多い | **AES-256-GCM + DTLS（E2EE二重暗号化）** |
| **暗号鍵の管理** | サーバー側管理 | **送信者・受信者のみ（PINからPBKDF2で導出）** |
| **データ改ざん検知**| なし、またはサーバー依存 | **SHA-256 ハッシュ値による自動突合検証** |
| **インターネット遮断環境**| 利用不可 | **動的QR光転送 または 同一LAN手動SDP直接通信が可能** |

## ホスト・公開方法

本システムは **HTML / CSS / JavaScript のみで構成された完全な静的SPA（Single Page Application）** です。

### 【方法1】GitHub Pages（推奨）
1. GitHubでリポジトリを作成し、本プロジェクトのファイルをプッシュします。
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/DefendEager/p2ptransfer.git
   git push -u origin main
   ```
2. リポジトリの **Settings** ➔ **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選び、Branch を `main` / `/(root)` に設定して **Save** をクリックします。

### 【方法2】Cloudflare Pages
1. Cloudflareダッシュボードで **Workers と Pages** ➔ **Pages** を選択。
2. 本フォルダをドラッグ＆ドロップしてデプロイします。

## 使い方ガイド

### ① オンライン接続（PINコード / QRコード）
1. 送信側端末と受信側端末の両方で本システムを開きます。
2. PC画面の **QRコード** をスマホのカメラでスキャンするか、**6桁PINコード** を入力して「接続」を押します。
3. 接続中いつでも「中止」ボタンでキャンセル可能です。

### ② 厳格セキュリティ下モード（動的QR光転送）
1. 接続タブを **「厳格セキュリティ下 (動的QR)」** に切り替えます。
2. 送信側でファイルを選択し「動的QR送信を開始」を押すと、画面に高速アニメーションQRが表示されます。
3. 受信側で「カメラ起動・連続スキャン開始」を押し、送信画面を撮影すると自動で全パケットが収集・復元されます。

### ③ 閉域網・完全オフライン接続（手動SDP交換）
1. 接続タブを **「閉域網・オフライン」** に切り替えます。
2. 端末AでオファーSDPを生成してコピー ➔ 端末Bで貼り付けてアンサーSDPを生成 ➔ 端末AでアンサーSDPを適用して接続します。
