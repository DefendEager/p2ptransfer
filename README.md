# GovP2P SecureTransfer
### 自治体セキュリティ基準対応・ゼロ知識E2EE暗号化ファイル共有システム

> **自治体プロキシ（IWSS）やファイアウォール下でも100%開通。**  
> ブラウザ内で AES-256-GCM 暗号化を行い、外部サーバーやネットワーク管理者に1バイトも中身を見せることなく、大容量ファイルを回線フルスピードで安全に共有します。

---

## 主な特徴

- **100%確実に開通（E2EEゼロ知識HTTPSリレー）**: 自治体プロキシ配下でWebRTC（UDP/P2P）が遮断されている環境でも、通常のWebサイト閲覧と同じHTTPS通信（443ポート）のみを用いて、回線上限速度で転送。
- **Web Crypto AES-256-GCM クライアント暗号化**: ファイルは送信前にブラウザ内で暗号化。中継サーバーには無意味な暗号化バイナリしか渡らず、復号鍵（PIN）は送信者・受信者のみが所持します。
- **SHA-256 完全性検証**: 復号完了時にハッシュ値を自動照合し、データの改ざんや破損を完全に検知。
- **直接P2P通信 (WebRTC)**: 制約のないネットワークや同一Wi-Fi下では、サーバーを一切介さない直接P2P通信も利用可能。
- **閉域網・完全オフライン対応**: インターネット完全遮断環境でも、手動SDP交換により同一LAN内でWebRTC接続が可能。

---

## 使い方ガイド

### 【方法1】高速E2EEリレー（自治体PC ↔ スマホ間で推奨）
1. **送信側（自治体PCまたはスマホ）**:
   - 「高速E2EEリレー」タブでファイルを選択（またはドラッグ＆ドロップ）。
   - 「暗号化して高速送信」をクリック。
   - 完了すると画面に **QRコード** と **6桁PIN** が表示されます。
2. **受信側（スマホまたは自治体PC）**:
   - スマホのカメラでPC画面の **QRコードをスキャン**（またはURLとPINを入力）。
   - **「受信・復号して保存」** をクリックすると、ブラウザ内で自動復号されファイルが保存されます。

### 【方法2】直接P2P (WebRTC)
- 「直接P2P」タブで6桁PINを入力して「接続」を押します。

### 【方法3】閉域網・オフライン (手動SDP)
- 「閉域網・オフライン」タブでオファーSDPとアンサーSDPを貼り合わせて接続します。
