# GovP2P SecureTransfer 🔒
### 自治体セキュリティ基準対応・端末間直接通信（P2P）ファイル＆テキスト共有システム

> **外部サーバーを一切介さず、ブラウザ同士が直接つながる。**  
> 自治体PCの厳しいセキュリティ制限下から一般のスマートフォンまで、大容量ファイルとテキストを最高速・安全・簡単に共有できるゼロログP2Pシステムです。

---

## 🌟 主な特徴

- 🛡️ **完全サーバーレス＆ゼロログ**: ファイルやテキストデータは外部サーバーに1バイトも保存・中継されません。ブラウザ端末間で直接通信（WebRTC DataChannel）します。
- 🔐 **Web Crypto 二重暗号化 (E2EE)**: WebRTC標準のDTLS暗号化に加え、Web Crypto API による **AES-256-GCM** でチャンク単位二重暗号化。シグナリングサーバーやネットワーク管理者でも盗聴・復号は不可能です。
- ⚡ **徹底的な超高速化ロジック**: 
  - **64KB最適化チャンキング**: SCTP通信のMTUとバッファ効率を最大化。
  - **Backpressure（背圧）制御**: `bufferedAmountLowThreshold` によるイベント駆動ストリーミング。ブラウザのバッファ溢れやメモリ枯渇（OOM）を防ぎ、LAN/回線の理論上限速度を引き出します。
  - **オンデマンドスライス**: `Blob.slice()` による逐次読み込みで、数GBクラスの大容量ファイルでも安定転送。
- 🔍 **SHA-256 完全性検証**: 送信前と受信完了時にファイル全体のSHA-256ハッシュ値を自動計算・照合し、データの破損や改ざんを100%検知。
- 📱 **手間のない簡単接続**: 
  - **6桁PINコード入力**: 数字を入力するだけで即時ペアリング。
  - **QRコードスキャン**: スマホのカメラやPCのWebカメラでQRをかざすだけで一発接続。
- 🏢 **完全オフライン/閉域網（LGWAN等）対応**: インターネット通信が遮断された環境でも、画面上のSDPテキスト/QRコードを手動交換することで同一LAN内でWebRTC接続を確立可能。

## 🛡️ 自治体PC・金融機関でも安全とされる理由（セキュリティ仕様）

| セキュリティ項目 | 一般的なクラウドストレージ / ファイル転送サービス | GovP2P SecureTransfer |
| :--- | :--- | :--- |
| **データ保存場所** | 外部クラウドサーバー（漏洩・不正アクセスリスク） | **端末のメモリ内のみ**（外部保存ゼロ） |
| **通信経路** | 端末 ➔ 外部サーバー ➔ 相手端末 | **端末 ➔ 相手端末（直接通信）** |
| **暗号化強度** | サーバー側で復号可能な場合が多い | **AES-256-GCM + DTLS 1.3（E2EE二重暗号化）** |
| **暗号鍵の管理** | サーバー側管理 | **送信者・受信者のみ（PINからPBKDF2で導出）** |
| **データ改ざん検知**| なし、またはサーバー依存 | **SHA-256 ハッシュ値による自動突合検証** |
| **インターネット遮断環境**| 利用不可 | **完全オフライン・同一LAN直接通信が可能** |

## 🚀 最も簡単・安全・無料・無期限にホストする方法

本システムは **HTML / CSS / JavaScript のみで構成された完全な静的SPA（Single Page Application）** です。  
サーバーサイドのデータベースやバックエンドプログラムが不要なため、以下のサービスを利用することで**完全無料・無期限・維持費ゼロ・メンテナンス不要**で公開・運用できます。

---

### 【方法1】Cloudflare Pages（最も推奨 ⭐⭐⭐⭐⭐）
> **特徴**: 無料・無期限・帯域制限なし・世界最速水準のCDN・強力なDDoS保護・HTTPS標準適用。  
> 初心者でも **ZIPファイルをドラッグ＆ドロップするだけ（所要時間：約2分）** で公開できます。

#### 手順（Direct Upload方式：GitHub不要）
1. [Cloudflare](https://dash.cloudflare.com/sign-up) にアクセスし、無料アカウントを作成してログインします。
2. 左メニューから **「Workers と Pages」** ➔ **「Pages」** を選択します。
3. **「アセットをアップロード (Direct Upload)」** をクリックします。
4. プロジェクト名（例: `my-secure-transfer`）を入力し、本プロジェクトのフォルダ（`index.html` があるフォルダ全体）をZIP圧縮してアップロード、またはフォルダをそのままドラッグ＆ドロップします。
5. **「サイトをデプロイ」** をクリックします。
6. 数秒で `https://my-secure-transfer.pages.dev` のような安全な専用HTTPS URLが発行され、即座に無期限で利用可能になります。

---

### 【方法2】GitHub Pages（エンジニア向け ⭐⭐⭐⭐）
> **特徴**: 完全無料・無期限。GitHubリポジトリにプッシュするだけで自動公開。

#### 手順
1. GitHubで新しいパブリック（またはプライベート）リポジトリを作成します。
2. 本プロジェクトのファイルをリポジトリにプッシュします。
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/DefendEager/p2ptransfer.git
   git push -u origin main
   ```
3. リポジトリの **「Settings」** ➔ **「Pages」** を開きます。
4. **「Build and deployment」** の Source で **「Deploy from a branch」** を選び、Branch を `main` / `/(root)` に設定して **「Save」** をクリックします。
5. 約1分で `https://<ユーザー名>.github.io/<リポジトリ名>/` にて無料公開されます。

---

### 【方法3】自治体・組織内LAN Webサーバー（完全閉域網向け）
> **特徴**: 外部インターネットに一切接続できないLGWAN環境や機密LAN内での運用。

1. 本リポジトリの全ファイル（`index.html`, `css/`, `js/`, `libs/`）を、組織内の既存Webサーバー（IIS, Apache, Nginx等）のドキュメントルートに配置するだけです。
2. 全てのライブラリ（QRコード生成・スキャン、WebRTC制御スクリプト）は `libs/` フォルダ内に同梱されているため、**外部インターネットへのアクセスが一切遮断された環境でも100%スタンドアロンで動作**します。

## 📖 使い方ガイド

### ① オンライン接続（PINコード / QRコード）
1. 送信側端末と受信側端末の両方で本システムを開きます。
2. **スマホからPCに送る場合**: PC画面に表示された **QRコード** をスマホのカメラでスキャンするだけで自動接続されます。
3. **PC同士の場合**: 片方の画面に表示されている **6桁のPINコード** を、もう片方の入力欄に入力して「⚡ 接続する」をクリックします。
4. 接続が完了したら、ファイルをドラッグ＆ドロップして「🚀 高速送信を開始する」を押すか、テキストを入力して送信します。

### ② 完全オフライン接続（閉域網・手動SDP交換）
1. 上部のタブを **「🛡️ 閉域網・完全オフライン」** に切り替えます。
2. 端末Aで **「① オファーSDPを生成」** をクリックし、生成された文字列をコピーします。
3. 端末Bでその文字列を貼り付け、**「アンサーSDPを生成」** をクリックして生成された文字列をコピーします。
4. 端末Aでそのアンサー文字列を貼り付け、**「接続を完了する」** をクリックします。
5. これにより、外部シグナリングサーバーを一切使わずに同一LAN内でP2P接続が確立します。
