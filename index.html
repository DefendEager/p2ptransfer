セキュリティ仕様と接続状態

1. サーバー非経由・完全P2P (ゼロログ)
ファイルやテキストはクラウドや外部サーバーに一切保存・中継されません。ブラウザ端末間で直接通信します。
2. Web Crypto 二重暗号化 (E2EE)
WebRTC DTLS 暗号化に加え、Web Crypto API による AES-256-GCM で二重暗号化。中間者やシグナリングサーバーでも復号は不可能です。
3. 厳格セキュリティ下 (動的QR光転送) 対応
外部ネットワーク通信が一切不通の環境でも、Gzip圧縮＋画面の動的QRコードとカメラ連写により完全スタンドアロンで転送可能です。
4. SHA-256 完全性検証
転送完了時に自動でSHA-256ハッシュ値を照合し、データの破損や改ざんを検知します。
