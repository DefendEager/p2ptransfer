🛡️ 自治体セキュリティ基準と技術仕様

1. サーバー非経由・完全P2P (ゼロログ)
ファイルやテキストはクラウドや外部サーバーに一切送信・保存されません。ブラウザ端末間で直接通信します。
2. Web Crypto 二重暗号化 (E2EE)
トランスポート層の WebRTC DTLS 1.3 暗号化に加え、Web Crypto API による AES-256-GCM で二重暗号化。中間者やシグナリングサーバーでも復号は数学的に不可能です。
3. SHA-256 完全性検証
大容量ファイル転送完了時に自動でSHA-256ハッシュ値を照合し、データの破損や改ざんがないことを保証します。
4. 閉域網・完全オフライン対応
外部インターネットが遮断されたLGWANや隔離LAN環境でも、手動SDP/QR交換により100%動作します。
